# 更新日志 Changelog

## 械黑 GB Frex Sans GB v1.100 （2025/10/10）

-   应上流厂商威胁，本计划西文名称由 "Flex Sans" 更改为 "Frex Sans"。更新字体前建议删除旧字体文件以确认使用最新版本。  
    Due to the threat from upstream font foundry, this project has changed name from "Flex Sans" to "Frex Sans". Please delete the old version before updating to ensure using the latest version.
-   将 OpenType `ss02` 特性映射至单层拉丁小写 g。  
    Map Opentype `ss02` feature to single-storey lowercase Latin g.
-   修改部分插值错误汉字。  
    Fix some interpolation bugs.
-   新增部分汉字，未根据任何字表添加。  
    New ideographs (not following any existing character tables).
-   VF 版：修改未支援可变字体环境默认使用 Regular 字重。  
    VF version: Change the default weight to Regular in unsupported environment.

> [!NOTE]  
> Windows 预览有反馈出现汉字宽度异常，是 Windows 的问题而非本字体问题。日常使用不会受影响。  
> Windows font viewer may display incorrect spacing for hanzi, this is a problem with Windows and not the font. This will not affect daily usage.
